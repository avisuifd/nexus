## 6. Features that change settings on your PC

A few features change settings on your computer, **only when you turn them on or click the button**:

- **Launch at startup** adds NEXUS to Windows startup.
- **Rocket League live stats** can edit Rocket League's `TAStatsAPI.ini` to turn on its Stats API (with a Windows admin prompt).
- **Phone Drop › Allow through firewall** adds a Windows Firewall rule for Phone Drop's ports (with an admin prompt).
- **Text shortcuts** runs a small keyboard helper that types your saved text when you type a shortcut.

You can undo each of these (turn the setting off, or remove the file change or firewall rule).
